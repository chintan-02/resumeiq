# Applied ML Engineer, Northbeam Retail Analytics (fictional)

## About the role

You will build forecasting and classification services for retail clients across Western Canada.

## Requirements

- Experience with Python and scikit-learn
- Build and deploy machine learning models as REST APIs
- Hands-on experience with Docker
- Write SQL to build training datasets
- Design evaluation sets and report model metrics
- Lead the deployment of models to a cloud platform such as Azure or GCP
- Explain model results to non-technical stakeholders

## Nice to have

- Experience with experiment tracking tools like MLflow
- Familiarity with Kubernetes
- Experience with Airflow

## Benefits

Hybrid work, learning budget, health spending account.
